# Operator and formalization entry

Read the [operator architecture](../docs/architecture/OPERATORS_EN.md), [machine catalogue](../spec/operator_catalog.yaml), [formalization conventions](../docs/methods/FORMALIZATION_EN.md), [EIDOS reuse assessment](../docs/architecture/EIDOS_SKILL_REUSE_EN.md) and [project skill](../.agents/skills/horisma-research-contracts/SKILL.md).

These are contracts for future implementation and qualification. Reusing a library, producing a file or showing a green dashboard cannot approve historical findings. Horisma scientific state remains in Horisma-owned storage.

The [PFLM extension](../docs/architecture/PFLM_LOCAL_OPERATOR_EN.md) is an optional installed local pattern observer/ranker. It complements deterministic paragraph/citation candidate retrieval and grants no factual-support or automatic-exclusion authority.
