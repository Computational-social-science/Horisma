# Horisma clean-rebuild design review

**Date:** 4 November 2026. **Decision status:** proposed research baseline, not implementation acceptance.  
**Workspace:** `E:/2026-AI4S/Horisma`.  
**Canonical proposal:** [Research proposal, design 0.1](Horisma_Terminological_Provenance_Project_Research_Proposal_EN.md).

## Decision

Build an auditable claim-and-contribution corpus first. Generate books from it, evaluate models against independently adjudicated evidence, and pursue a separately identified behavioural study. Keep the six operator interfaces, but stage their implementation. Treat the previous Horisma repository as an untrusted legacy input, not a scientific or engineering foundation.

The initial architect position was evidence-first: a microbook is a useful derivative, while a credible benchmark and behavioural paper need independent evidentiary and identification foundations. Its strongest reasons were ambiguous historical priority, the inability of a product to establish causality, and the need to bound a free local operation. Its main risk was delaying useful output through excessive infrastructure design.

## Independent strategic voices

The council considered the compact project brief independently, without receiving the architect's preferred answer. These are strategic reviews, not external academic peer review or factual verification.

**Skeptic:** Anchor the project in a small attribution-audit corpus and a falsifiable evaluation question. Miscredit, omitted acknowledgement, disputed priority and unequal recognition are different phenomena. A controversy-selected corpus is not ground truth or a prevalence sample. Source authenticity and precise passage support must both be checked; otherwise the benchmark can reward citation laundering.

**Pragmatist:** Ship one bounded vertical slice: evidence passages, claims, uncertainties, independent decisions and an English microbook together. Defer portraits and broad multilingual automation until they serve a measured question. Local maintenance should handle tractable orchestration and candidate work. Appropriate abstention and correction may be more informative than fluent narrative production.

**Critic:** Prevent circular authority, where generated profiles become book claims and then benchmark labels. Separate allegations, documented findings and unresolved interpretations. Public controversy is subject to selection, interference and reputational harm; it cannot become a causal experiment by being labelled one. Independent adjudication and corrections are part of the research design.

**Consensus:** Evidence, uncertainty and independent review anchor the project. No voice supports immediate autonomous publication or treating the portal as an NHB result.

**Strongest dissent:** The skeptic would simplify more aggressively than a six-operator implementation. The synthesis retains the requested contracts but implements only the minimal evidence-to-book path first. This protects extensibility without requiring six mature subsystems before the pilot can be assessed.

## Material corrections to the brief and legacy assumptions

| Assumption | Clean-rebuild decision |
|---|---|
| The old project is a reusable baseline | Reset scientific and operational readiness; verify sources individually and do not import old labels or progress scores |
| Latest JACS is the current universal standard | Retain versioned JACS compatibility; recognize HECoS/CAH replacement in UK subject coding and separate research-domain mappings |
| An early date proves coinage or delivery | Represent attestation, naming, scheduled presentation, actual delivery and publication as different claims |
| Miscredit implies theft or misconduct | Label claim-evidence discrepancies; do not infer intent or collapse contribution roles |
| Generated portraits remove rights concerns | Make them optional, labelled, separately licensed and excluded from evidentiary/manuscript-figure roles by default |
| Automated review can approve truth | Automated findings assist accountable historical adjudication and release review |
| Six fluent translations establish multilingual validity | Preserve claim IDs and uncertainty; qualify each language with bilingual review |
| Public feedback is a large causal experiment | Treat it as descriptive unless a separate ethically approved identification design supports a causal claim |
| An open-source wrapper makes every model open source | Check runtime, checkpoint, dataset and redistribution licenses independently |
| Free tiers are a zero-cost operating model | No mandatory proprietary/paid API, no expiring-credit dependency and no hosted fallback |
| Paywalls should be solved by repeated automated retrieval | Suspend the dependency and create a traceable human source request; never fabricate unseen passages |
| A framework install or monitor green state establishes readiness | Require Horisma-specific end-to-end, scientific and operational acceptance |

## Source check and limits

The proposal uses primary/official sources rather than the old Horisma narrative:

- [HESA JACS](https://www.hesa.ac.uk/support/documentation/jacs) and [HECoS/CAH](https://www.hesa.ac.uk/support/documentation/hecos): official indexed documentation supports the 2019/20 replacement. Direct fetch was restricted; the exact currently downloadable vocabulary release was not certified. The proposal therefore requires version/download verification at implementation and does not invent a latest version.
- [OECD Frascati Manual](https://www.oecd.org/en/publications/frascati-manual-2015_9789264239012-en.html): reference for a research-oriented classification, not an automatically equivalent historical ontology.
- [Merton's 1968 primary reprint](https://garfield.library.upenn.edu/merton/matthew1.pdf): supports the bibliographic anchor and explicit reference to Zuckerman's interview research. The local 1964/1988 files have not been fully adjudicated by this proposal revision.
- [AttributionBench](https://aclanthology.org/2024.findings-acl.886/), [HiST-LLM](https://papers.nips.cc/paper_files/paper/2024/hash/38cc5cba8e513547b96bc326e25610dc-Abstract-Datasets_and_Benchmarks_Track.html) and [Huber et al.](https://doi.org/10.1073/pnas.2205779119): establish relevant existing work. This is not an exhaustive literature review or proof of novelty.
- [NHB Registered Reports](https://www.nature.com/nathumbehav/submission-guidelines/registeredreports), [publisher AI policy](https://www-cm10rc.springernature.com/gp/policies/editorial-policies/ai-manuscript-preparation), [U.S. Copyright Office AI resources](https://www.copyright.gov/ai/) and [GitHub billing documentation](https://docs.github.com/en/billing/concepts/product-billing/github-actions): support the relevant policy boundaries. Recheck applicable versions, jurisdiction and service limits before implementation/publication.

No new historical priority verdict, copyright clearance, benchmark score, participant finding, model qualification or journal acceptance is asserted.

## Outstanding decisions before implementation

Name the responsible editor, independent adjudicator and initial bilingual reviewer; select the bounded pilot source set; freeze contribution-role definitions; confirm source access and reuse rights; define the held-out sampling frame; and approve the host-specific local runtime/resource manifest. These are explicit readiness conditions, not facts supplied by the legacy repository.
