# Horisma 方案状态说明

[公开科研目标](MATTHEW_EFFECT_INTAKE_EN.md#research-objectives)概述 v2.2 的研究问题、Matthew Effect 首例实验和拟开展的外部对照。

## 科研目标

Horisma 优先追求有关专业术语起源、贡献分工、社会认可和跨领域传播的原创历史发现。围绕具备明确词义、时间、语言、贡献角色和档案范围的原子主张，提出三个可检验的问题。

| 研究目标 | 需要什么证据 |
|---|---|
| R1 · 历史考证 | 用可定位的原件记录限定范围内的词语用例、命名、概念形成、实证工作、署名和传播。分别记录事件、来源陈述与系统获知的时间。 |
| R2 · 测量效度 | 检验更正版次、日期、词义或角色后，历史判断是否发生有意义的变化。对不同方法使用同一批归因机会，在可达到的共同覆盖率上报告差错和弃答。 |
| R3 · 可推广的解释 | 用独立术语、事件和来源家族检验跨案例规律，并比较史料存续和可得性、转述压缩、命名惯例及声望等竞争解释。历史因果效应需要单独的识别设计。 |
