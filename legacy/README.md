# legacy

Quarantine catalogue for existing materials left in place. Catalogue membership does not grant scientific, copyright or software trust.

`material_inventory.json` is the original 625-entry observation with byte hashes. `material_availability.json` is a later availability observation; it currently records three missing PDFs and retains their original hashes. Do not remove entries or overwrite prior bindings to make availability appear complete. The cause of missing files is not established.

The full original-material inventory is local-only and excluded from the clean technical GitHub snapshot. The small availability summary is a diagnostic checkpoint, not a scientific corpus or accepted finding. The rebuilt repository does not restore the old implementation/history.
